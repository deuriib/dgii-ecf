# Examples

Runnable examples for both SDKs, plus DGII sample fixtures.

## Contents

| Path | Description |
| --- | --- |
| `fixtures/test.xml` | Full DGII e-CF sample document (from [victors1681/dgii-ecf](https://github.com/victors1681/dgii-ecf), MIT). |
| `fixtures/invoice-31.xml` | Minimal unsigned ECF-31 invoice used by the signing examples. |
| `fixtures/invoice-31.json` | The same invoice as compact JSON, used by the transform examples. |
| `python/` | Python examples (`py-dgii-ecf`). |
| `typescript/` | TypeScript examples (`@deuriib/dgii-ecf`). |

## Quick start

### Python

```bash
cd python
uv sync
uv run python generate_cert.py
uv run python sign_xml.py
```

### TypeScript

```bash
cd typescript
bun install
bun run generate-cert
bun run sign
```

See each folder's README for details. Outputs are written to `output/`
(gitignored).

> ⚠️ Certificates generated by the examples are throwaway self-signed certs for
> offline testing. They are **not** valid DGII certificates and will be rejected
> by DGII.
