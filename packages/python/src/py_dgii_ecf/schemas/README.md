# Bundled DGII XML Schemas

Official schemas published by the DGII, bundled so `validate_document` works
offline.

- `MANIFEST.json` records the source URL, `sha256` and size of every file, plus
  the three published schemas that do **not** compile.
- The repository mirror for examples and tests lives at
  `examples/fixtures/schemas/`.

See that directory's `README.md` for the per-schema status.
